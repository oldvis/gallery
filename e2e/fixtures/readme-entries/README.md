# README entry image fixtures

Offline plates for `pnpm docs:screenshot`. Each file is named by visualization UUID and listed in `manifest.json`.

These are **reduced-resolution** copies of the David Rumsey source images (long edge ≈ 640px, JPEG quality ≈ 70). They only need to look distinct in the README gallery shot — not archive quality. Do not treat them as substitutes for the originals.
